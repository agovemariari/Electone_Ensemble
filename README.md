# エレクトーン 合奏アシスタント

電子オルガン（エレクトーン）での合奏時に、キーボード奏者のトリガーノートを認識して、自動的に和音を出力するアシスタントプログラムです。さらに、対旋律機能により、トリガーに応じてMIDIクロック同期の対旋律を自動演奏できます。

## 主な機能

### 1. MIDIトリガー認識と和音出力
- **トリガーベース伴奏エンジン**：特定のノート（トリガーノート）を入力として認識
- **自動和音生成**：トリガーに対応する複数の和音ノートを自動的に出力
- 複数のトリガーパターンをマッピングで管理可能

### 2. 対旋律シーケンサー（新機能）
- **MIDIクロック同期**：ELB-02など外部機器からの同期クロックに基づいて対旋律を演奏
- **グラフィカルエディタ**：ピアノロール風のUI で対旋律を作成・編集
- **タイミング制御**：MIDI クロック単位（24/4分音符）での細かいタイミング設定
- **可変長対旋律**：1〜4小節の範囲で対旋律の長さを設定可能
- **複数ノート対応**：1つのタイミングで複数のノートを同時発音可能

### 3. MIDI接続管理
- MIDIポートの自動検出・選択
- MIDI入力（キーボード）と出力（シンセサイザーなど）の接続管理
- ポート状態のリアルタイム表示

### 4. パッチ（音色）設定
- **出力チャンネル**：複数チャンネルへの出力に対応
- **バンク設定**：MSB/LSB値で音色バンクを選択
- **プログラムチェンジ**：特定の音色への切り替え
- **エフェクト調整**：
  - ボリューム制御
  - エクスプレッション（音の強弱）
  - パンニング（左右の音の配置）
  - リバーブ/コーラスエフェクト

### 5. GM初期化機能
- **GM（General MIDI）標準初期化**：Dominoに相当する設定で機器を初期化
- 演奏前の機器状態をリセット可能

### 6. トリガーマッピング管理
マッピングテーブルで以下を管理：
- **トリガー情報**：チャンネル、ノート
- **アクション情報**：出力する和音ノートのリスト
- **ベロシティ（音量）**：各和音の強さ
- **対旋律設定**：有効/無効、長さ、タイミング情報
- **名前/説明**：マッピングの識別用名前

### 7. 小節トラッキング
- 演奏中の小節番号をリアルタイム表示
- タイミング同期機能

### 8. ログ・デバッグ機能
- エンジンからのログをUI上にリアルタイム表示
- トラブルシューティング用の詳細情報記録

### 9. 設定の永続化
- 現在のマッピングと設定をJSON形式で保存
- ファイルの読み込み・保存機能

## 推奨される使用フロー

1. **MIDI更新** → MIDIポート一覧を最新化
2. **入出力選択** → MIDI INとMIDI OUTを選択
3. **接続** → 選択したポートに接続
4. **GM初期化** → 出力機器をリセット
5. **開始** → エンジンを起動して待機
6. **トリガー送信** → キーボードからトリガーノートを演奏

## 対旋律の使用方法

### 対旋律編集ダイアログを開く
1. マッピングテーブルで編集したい行を選択
2. **「対旋律編集」ボタン** をクリック

### 対旋律を作成する
1. **設定タブ**で「対旋律を有効にする」をチェック
2. 小節の長さを設定（1〜4小節）
3. **「+ 追加」ボタン** でイベントを追加
4. 各イベントで以下を設定：
   - **Timing (Clock)**：発音するタイミング（0〜96×小節数、24クロック/ビート）
   - **Notes**：発音するノート（複数可、カンマ区切り）
   - **Velocity**：ベロシティ（1-127）
   - **Duration (Clock)**：ノートを発音し続ける期間

### 例：4分音符でのビート表示
- クロック 0 = 小節開始
- クロック 24 = 2拍目
- クロック 48 = 3拍目
- クロック 72 = 4拍目

## ファイル構成

| ファイル | 説明 |
|---------|------|
| `engine.py` | MIDIエンジン実装（トリガー認識、和音出力、対旋律スケジューラー） |
| `ui.py` | Tkinterベースのユーザーインターフェース + 対旋律エディタ |
| `song.json` | マッピング設定ファイル（トリガー→和音の対応、対旋律設定） |

## 技術仕様

- **ノート指定形式**：MIDI整数（0-127）または文字列（例：C4, F#3, Bb2）
- **バックグラウンド処理**：MIDIエンジンはスレッド化して動作
- **NOTE OFF ポリシー**：次のトリガーで全ノートをOFFにしてから新規ノートをON
- **クロック処理**：MIDI同期クロック（24/4分音符）でタイミング管理
- **対旋律更新**：毎クロック単位でスケジューラーをチェック
- **設定フォーマット**：JSON（UTF-8）

## トリガーマッピング例

### 基本的な和音マッピング
```json
{
  "name": "Cue_A_minor",
  "trigger": {
    "ch": 1,
    "note": 76
  },
  "action": {
    "notes": [57, 60, 64, 69],
    "velocity": 75
  },
  "countermelody": {
    "enabled": false,
    "bar_length": 1,
    "sequence": []
  }
}
```

### 対旋律付きマッピング
```json
{
  "name": "Cue_C_major",
  "trigger": {
    "ch": 2,
    "note": 55
  },
  "action": {
    "notes": [60, 64, 67, 72],
    "velocity": 80
  },
  "countermelody": {
    "enabled": true,
    "bar_length": 1,
    "sequence": [
      {
        "timing_clock": 0,
        "notes": [60],
        "velocity": 70,
        "duration_clock": 12
      },
      {
        "timing_clock": 24,
        "notes": [64],
        "velocity": 75,
        "duration_clock": 12
      },
      {
        "timing_clock": 48,
        "notes": [67],
        "velocity": 70,
        "duration_clock": 12
      }
    ]
  }
}
```

この例では、トリガーとしてチャンネル2でノート55を受信すると、まず和音（60, 64, 67, 72）が出力され、同時に対旋律が開始されます。対旋律は1小節分の設定で、タイミング0（開始）、24（2拍目）、48（3拍目）で異なるノートを発音します。
