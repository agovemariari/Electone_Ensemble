# エレクトーン 合奏アシスタント 使い方

## 概要
MIDI入力の「トリガー(note on)」に反応して、あらかじめ登録した和音やフレーズを演奏します。
フレーズはMIDIクロックに同期して複数タイミングで発音できます。

## 起動方法
```powershell
python ui.py
```

## 基本操作
1) 「MIDI更新」でIN/OUTを選択  
2) 「接続」  
3) 必要なら「GM初期化」  
4) 「開始」

停止するときは「停止」。

## マッピングの編集
テーブル1行が1つのトリガーです。
- Trigger CH / Trigger Note: 入力側のnote on
- Action Notes: 同時に鳴らす和音 (例: `C4,E4,G4`)
- Vel: ベロシティ
- Phrase (JSON): フレーズ設定 (任意)

「選択行を編集」から各項目を編集できます。

### フレーズの書き方
Phrase (JSON) にJSONを入力します。空欄なら単発和音のみ再生します。

例: 8分音符でフレーズ
```json
{"unit":"8n","gate":"8n","pattern":["C4","E4","G4","E4"]}
```

例: 明示的なクロック指定 (ppqn=24なので8分音符は12)
```json
{
  "gate_clocks": 12,
  "steps": [
    {"offset_clocks": 0, "notes": ["C4"]},
    {"offset_clocks": 12, "notes": ["D4"]},
    {"offset_clocks": 24, "notes": ["E4"]}
  ]
}
```

### フレーズのキー
- `unit`: `"8n"` のように音価指定。`pattern`と組み合わせる。
- `pattern`: 配列。`"C4"`のようなノート、または`"-"`/`"rest"`で休符。
- `steps`: 明示的なタイミング指定。`offset_clocks`はMIDIクロック数。
- `gate` / `gate_clocks`: ノートオフまでの長さ (省略可)

## CH別パッチ設定
左側の「CH別パッチ（CH4-16）」で、チャンネルごとに音色や音量を設定できます。
空欄はデフォルト値（上のGMパッチ設定）を使います。

保存される例:
```json
{
  "patch": {
    "bank_msb": 0,
    "bank_lsb": 0,
    "program": 48,
    "volume": 100,
    "expression": 127,
    "pan": 64,
    "reverb": 40,
    "chorus": 0,
    "channels": {
      "4": {"program": 48, "volume": 100},
      "5": {"program": 40, "volume": 90}
    }
  }
}
```

## スコア入力（Phase 1）
下の「スコア入力（CH4-16 / 16分グリッド）」で、cueごとにCH4-16のフレーズを入力できます。
1セルが16分音符1つ分で、`C4`や`C4,E4`のように入力します。

使い方:
1) マッピングの「名前」をcue名として使う  
2) スコアのCueで対象を選択  
3) グリッドに音符を入力  
4) 「反映」で保存

補足:
- 16分以外は今後拡張予定（現状は固定）
- cueにスコアがある場合、Phrase/Action Notesより優先して再生されます
- スコア再生もMIDIクロックに同期します
- cue名はユニークにしておくのがおすすめです

## Cueトラック（Phase 2）
CH1-3のトリガーを「Cueトラック」として別枠表示します。
- Cue名 / Trigger CH / Trigger Note を一覧化
- Score列でスコア紐付けの有無を表示
- 行を選ぶとスコア編集のCueが切り替わります

## CCトラック（ベロシティ/音色変化）
スコア入力の下にある「CCトラック」で、CC11/CC74のポイント列を入力できます。
任意タイミングでのクレッシェンド/音色変化に使えます。

書式:
- `step:value` を空白またはカンマで並べます
- stepは1から始まる16分単位 (小節数×16)
例:
```
1:40 5:60 9:80 13:100
```

補足:
- CC11: Expression (音量変化)
- CC74: Brightness (擬似フィルタ)

## Web UI（試作）
機能は凍結し、UI移行のためのWeb試作を追加しました。
まだバックエンド連携はしていないため、見た目とレイアウトの確認用です。

起動方法:
```powershell
Start-Process web\index.html
```

譜面エディタ（Web試作）:
- 可変スタッフ / 拍子変更 / 音符配置（1/1,1/2,1/4,1/8,1/16）
- CH1-3長押し→CH4+へドラッグで紐づけ
- 消しゴムツール / Ctrl+Zで取り消し
- 保存(JSON)で譜面モデルを書き出し

## 注意点
- フレーズはMIDIクロックが来たときに進みます。クロックが無い環境だと、offset 0の音だけが鳴ります。
- 次のトリガーが来ると、前のフレーズ/和音は止まります。
